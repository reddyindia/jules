# افزونه تحلیلگر (Tahlilgar Analyzer) برای وردپرس

یک افزونه قدرتمند وردپرسی برای ساخت و مدیریت فرم‌های پیشرفته، همراه با یک داشبورد مدرن و کاربرپسند.

این افزونه با الهام از ابزارهای نظرسنجی پیشرو مانند پرسلاین، به شما امکان می‌دهد تا فرم‌های پیچیده را به سادگی از طریق یک رابط کاربری کشیدن و رها کردن (drag-and-drop) طراحی کرده و آن‌ها را در هر کجای سایت خود با استفاده از یک شورت‌کد ساده نمایش دهید.

---

## ✨ ویژگی‌های کلیدی

- **داشبورد مدرن:** یک داشبورد مدیریتی زیبا و واکنش‌گرا با قابلیت تغییر تم (روشن/تاریک) و منوی کناری هوشمند.
- **فرم‌ساز پیشرفته:**
  - رابط کاربری کشیدن و رها کردن (Drag-and-Drop) برای طراحی آسان فرم.
  - پشتیبانی از طیف گسترده‌ای از فیلدها:
    - صفحات خوش‌آمدگویی و پایانی
    - متن با اعتبارسنجی (ایمیل، URL، تلفن همراه ایران و...)
    - گروه‌بندی سوالات، درجه‌بندی، اولویت‌دهی و آپلود فایل.
    - فیلدهای مخفی و فیلدهای فقط خواندنی (برای متغیرهای محاسباتی).
- **نمایش آسان فرم:** با استفاده از شورت‌کد ساده `[tahlilgar_form id="..."]` فرم‌ها را در هر برگه یا نوشته‌ای نمایش دهید.
- **ذخیره‌سازی پاسخ‌ها:** تمام پاسخ‌های ارسالی کاربران به صورت مجزا در پیشخوان وردپرس ذخیره و قابل مشاهده هستند.
- **زیرساخت مدرن:** استفاده از REST API وردپرس برای ارتباطات امن و پایدار بین فرانت‌اند و بک‌اند.
- **کیفیت کد بالا:** همراه با ابزارهای توسعه حرفه‌ای مانند Composer و PHP CodeSniffer برای اطمینان از کیفیت و پایداری کد.

## 🚀 نحوه استفاده

### ۱. فعال‌سازی افزونه
پس از نصب و فعال‌سازی افزونه، موارد زیر به صورت خودکار در وردپرس شما ایجاد می‌شوند:
- منوی جدیدی به نام **"Tahlilgar Forms"** در پیشخوان وردپرس.
- صفحات "Dashboard", "Login" و "Form Builder".
- انواع پست سفارشی "Forms" و "Submissions" برای ذخیره‌سازی داده‌ها.

### ۲. ساخت اولین فرم
- از منوی پیشخوان به **Tahlilgar Forms -> Form Builder** بروید.
- با کشیدن و رها کردن فیلدهای مورد نظر از پنل سمت چپ به صفحه اصلی، فرم خود را طراحی کنید.
- روی هر فیلد کلیک کنید تا تنظیمات آن (مانند عنوان، متن جایگزین، نوع اعتبارسنجی و...) را ویرایش کنید.
- پس از اتمام طراحی، روی دکمه **"ذخیره فرم"** کلیک کنید. یک نام برای فرم خود انتخاب کرده و آن را ذخیره کنید.

### ۳. نمایش فرم در سایت
- به منوی **Tahlilgar Forms -> Forms** بروید. در اینجا لیست تمام فرم‌هایی که ساخته‌اید را مشاهده می‌کنید.
- شناسه (ID) فرم مورد نظر خود را از ستون ID پیدا کنید.
- یک برگه یا نوشته جدید ایجاد کنید (یا یکی از برگه‌های موجود را ویرایش کنید).
- شورت‌کد زیر را در ویرایشگر متن قرار دهید و شناسه فرم خود را جایگزین `123` کنید:
  ```
  [tahlilgar_form id="123"]
  ```
- برگه را منتشر یا به‌روزرسانی کنید. اکنون فرم شما در آن صفحه برای کاربران نهایی قابل مشاهده و پر کردن است.

### ۴. مشاهده پاسخ‌ها
- برای مشاهده پاسخ‌های ارسال‌شده، از منوی پیشخوان به **Tahlilgar Forms -> Submissions** بروید.

## 👨‍💻 برای توسعه‌دهندگان

این پروژه با رعایت استانداردهای مدرن توسعه وردپرس ساخته شده است.

### مدیریت وابستگی‌ها
این پروژه از `Composer` برای مدیریت وابستگی‌های توسعه (PHP CodeSniffer) استفاده می‌کند. برای نصب وابستگی‌ها، دستور زیر را در ریشه پروژه اجرا کنید:
```bash
composer install
```

### بررسی استاندارد کدنویسی (Linting)
ما از `PHP_CodeSniffer` به همراه مجموعه قوانین `WordPress-Core` برای اطمینان از کیفیت کد استفاده می‌کنیم. برای بررسی کدها، از اسکریپت Composer زیر استفاده کنید:
```bash
composer run-script lint
```
این دستور به صورت خودکار توسط GitHub Actions نیز در هر Push و Pull Request اجرا می‌شود. فایل پیکربندی قوانین در `phpcs.xml.dist` قرار دارد.
